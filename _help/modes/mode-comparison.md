| | Adventure | Casual | Defense |
|---|---|---|---|
| Goal | Reach target score | Survive waves | Survive waves |
| Timer | Yes | No | No |
| Lives | None (time is the limit) | 3 hearts | Base shield + base |
| Slime lifetime | 3 to 5 s | 5 s | Never expire |
| Bad slimes | Yes (Poison, Trap) | No | No |
| Pets | Limited uses | Unlimited, long cooldown | Unlimited, long cooldown |
| Coins | Per level + Money slimes | 10 per wave | 15 per wave |
| Record bonus | None | 100 coins | 100 coins |
| Unlock | Always | Level 5 | Mode select |
| Leaderboard | None | Best wave | Best wave |

## Which one to play

- Want a goal and progress? **[Adventure](/help/modes/adventure-mode/)**.
- Want a relaxed, endless run? **[Casual](/help/modes/casual-mode/)**.
- Want a tense, strategic run? **[Defense](/help/modes/defense-mode/)**.
