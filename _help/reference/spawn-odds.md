Each time a slime spawns, one type is chosen at random from the level's list using these weights. Values are percentages.

## Casual Mode

| Slime | Chance |
|---|---|
| Normal | 50% |
| Shield | 15% |
| Ghost | 10% |
| Mirror | 8% |
| Blind | 7% |
| Slow-Mo | 7% |
| Heart | 3% |

## Defense Mode

| Slime | Chance |
|---|---|
| Normal | 40% |
| Shield | 18% |
| Ghost | 15% |
| Chain-Reaction | 10% |
| Money | 10% |
| Explosive | 7% |
