Terms used across this wiki.

| Term | Meaning | Read more |
|---|---|---|
| **Adventure Mode** | The 50-level campaign with target scores and timers. | [Open](/help/modes/adventure-mode/) |
| **Aftershock** | Rumble's passive: every 5th good pop explodes. | [Open](/help/pets/rumble/) |
| **Base** | What you defend in Defense Mode. Has one shield. | [Open](/help/modes/defense-mode/) |
| **Bad slime** | A slime that punishes you for tapping it. Only Poison and Trap. | [Open](/help/slimes/slime-types/) |
| **Big Target** | Chubby's ability, 150% slime size. | [Open](/help/pets/chubby/) |
| **Casual Mode** | Endless wave mode with no timer. Older strings call it Waves Mode. | [Open](/help/modes/casual-mode/) |
| **Checkpoint** | A saved wave every 5 waves in Defense Mode. | [Open](/help/modes/defense-mode/) |
| **Combo** | A counter of consecutive good pops. Visual only. | [Open](/help/reference/score-and-multipliers/) |
| **Companion** | An older helper system, removed in 2.0. Maximus was one. | [Open](/help/pets/maximus/) |
| **Cooldown** | The wait before an ability pet can be used again. | [Open](/help/reference/pets-in-endless-modes/) |
| **Defense Mode** | 360-degree base defense mode. | [Open](/help/modes/defense-mode/) |
| **Endless mode** | Casual or Defense Mode, which have no end. | [Open](/help/modes/mode-comparison/) |
| **Explosive** | The in-game name of the Explosion slime. | [Open](/help/slimes/explosion-slime/) |
| **Good slime** | Any slime that is safe to tap. | [Open](/help/slimes/slime-types/) |
| **Gravedigger** | Bones' passive: 30% chance to rescue an expiring slime. | [Open](/help/pets/bones/) |
| **Guard** | Pet whose shield blocks penalties. | [Open](/help/pets/guard/) |
| **Hearts** | Your lives in Casual Mode (3). | [Open](/help/modes/casual-mode/) |
| **Invulnerability** | Brief protection after a hit (1.5 s). | [Open](/help/modes/defense-mode/) |
| **Lifetime** | How long a slime stays on screen before expiring. | [Open](/help/reference/slime-comparison/) |
| **Linked** | State of slimes after a Chain-Reaction slime is popped. | [Open](/help/slimes/chain-reaction-slime/) |
| **Mega Combo** | The x2 score slime. | [Open](/help/slimes/mega-combo-slime/) |
| **Mirror Pop** | Echo's ability. | [Open](/help/pets/echo/) |
| **Multiplier** | A factor applied to points you earn. | [Open](/help/reference/score-and-multipliers/) |
| **Overkill** | Flash's passive: coins for very fast pops. | [Open](/help/pets/flash/) |
| **Passive pet** | A pet that works automatically. | [Open](/help/pets/companions-and-pets/) |
| **Pet** | A helper with an ability or passive effect. | [Open](/help/pets/companions-and-pets/) |
| **Purify** | Pet that turns bad slimes into normal ones. | [Open](/help/pets/purify/) |
| **Rarity** | Common, Rare, Epic, Mythic or Legendary. | [Open](/help/guides/coins-and-store/) |
| **Slime Discovery** | Panel shown the first time you meet a slime type. | [Open](/help/guides/tutorial/) |
| **Surf level** | Every 5th Adventure level, with sliding slimes. | [Open](/help/modes/surf-mode/) |
| **Surge** | Every 5th Defense wave: more slimes, faster spawns. | [Open](/help/modes/defense-mode/) |
| **Target score** | Points needed to win an Adventure level. | [Open](/help/modes/adventure-mode/) |
| **Wave** | A group of slimes in Casual or Defense Mode. | [Open](/help/reference/casual-wave-table/) |
| **Waves Mode** | Older in-game name for Casual Mode. | [Open](/help/modes/casual-mode/) |
| **Zone** | A set of ten Adventure levels sharing a backdrop. | [Open](/help/levels/all-levels/) |
